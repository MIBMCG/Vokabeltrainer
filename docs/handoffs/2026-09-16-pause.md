## Auf einem anderen Rechner starten

Voraussetzung: Git und Node.js ab Version 22.8.0. Ein frischer Clone:

```sh
git clone https://github.com/MIBMCG/Vokabeltrainer.git
cd Vokabeltrainer
git switch codex/google-drive-probe
git status --short --branch
git log -5 --oneline
npm test
```

Erwartet: 34 Tests bestanden, keine Fehler. Keine Zusatzpakete installieren. Bei einem bestehenden Clone zuerst lokale Änderungen prüfen, dann `git fetch origin` und auf den genannten Zweig wechseln; nichts blind zurücksetzen.

Der vollständige Code liegt auf **`codex/google-drive-probe`**. Die Dokumentation auf `main` kann als Wegweiser dorthin dienen; vor Codearbeit den Zweig prüfen. Die lokale Arbeitskopie unter `.worktrees/drive-probe/` ist lediglich eine Entwicklungsorganisation und muss auf einem anderen Rechner nicht nachgebildet werden. Browserdaten und Google-Anmeldung werden nicht durch Git übertragen.
